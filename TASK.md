# Задание: opencode-zai-quota

Спроектируй и реализуй opencode плагин для отображения 5-часового и недельного лимитов с pull механикой данных по таймеру.
Вдохновение бери из https://github.com/josvaal/opencode-zai-quota
Учти issue https://github.com/josvaal/opencode-zai-quota/pull/1
Спроектируй плагин с конфигурируемыми параметрами.
Плагин должен нативно выглядить и подхватывать темы opencode.
Пересмотри кардинально дизайн для этого плагина и перед выполнением согласуй со мной дизайн.

Работай как команда: планирование до кода, декомпозиция на задачи,
реализация, тесты, ревью. Артефакты процесса (план, декомпозиция) сохрани
в репозитории рядом с кодом.
